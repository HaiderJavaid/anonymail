# Anonymail overview

Anonymail is a small Chrome companion for private signups. The main action is deliberately explicit: the user right-clicks an editable field, Anonymail creates or reuses one disposable address, generates a separate website password, fills what it safely can, and opens the inbox.

The first release proves the workflow without accounts or paid infrastructure. The business path is an owned private-alias service, not resale of a public temporary-mail API.
